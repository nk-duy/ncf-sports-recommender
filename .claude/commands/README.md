## Cách sử dụng

Trong phiên làm việc với Claude Code hoặc AI Agent, người dùng có thể gõ trực tiếp tên lệnh kèm ngữ cảnh mong muốn.  
**Ví dụ:**  
- `/analyze Thêm tính năng đánh giá sao kèm hình ảnh thực tế cho sản phẩm`  
- `/plan Tích hợp gợi ý sản phẩm dựa trên lịch sử xem gần đây (Recently Viewed)`  
- `/review Kiểm tra pull request tối ưu truy vấn Beanie ODM trong OrderService`  
- `/document Cập nhật lại sơ đồ luồng dữ liệu thanh toán VNPay và QR Code`
